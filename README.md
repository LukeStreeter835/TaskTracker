# TaskTrack

TaskTrack is a command-line task manager created for CPS 310.

## Current Features

-Allows useres to store tasks in program
-Allows users to see tasks they added

## Running the Program

cd C:\Users\stree\OneDrive\Desktop\CPS310\TastTracker // Change directory to the correct filepath
python tasktrack.py // run the program


## Current Limitation

NOTE: Tasks are not saved after closing the program, so you can only view tasks you've written
during the same run of the program.
